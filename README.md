# Micro-C Deep Learning

This repository contains the reproducible Python implementation for supervised recognition and interpretation of known CHIN, OPCID, and CHID structures in Micro-C contact maps.

The executable project is in [`project/`](project/). See [`project/README.md`](project/README.md) for installation, data preparation, training, evaluation, and verification commands.

Large experimental inputs, generated NumPy matrices, model checkpoints, caches, and figure directories are intentionally excluded from Git. They remain local and must not be committed to GitHub. Data placement is documented in [`project/data/README.md`](project/data/README.md).

Compact Task 1 summaries are retained under `project/outputs/task1/`; full generated outputs can be reproduced locally from the scripts.
