# Task2C Unsupervised Grouping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** Produce a reproducible, frozen Task2C clustering and interpretation package without running Task2D.

**Architecture:** A read-only input loader validates Task2A/Task2B, a label-blind PCA/HDBSCAN core assigns primary clusters, and post-fit analysis/reporting adds known composition, diagnostics, heatmaps, and manifests. Smoke and Full have isolated output roots.

**Tech Stack:** Python, NumPy, pandas, scikit-learn 1.9 `HDBSCAN`, Matplotlib, existing Micro-C matrix/O/E readers.

**Spec:** `docs/superpowers/specs/2026-09-24-task2c-design.md`

## Global Constraints

- Primary population is paired-average candidate+Known embeddings only; Background, proposal scores, labels, rep1/rep2 rows excluded.
- PCA minimum cumulative variance >=0.95; HDBSCAN 5/5, Euclidean, eom, epsilon 0, no single cluster.
- Known labels only after HDBSCAN fit; UMAP visualization only; no Task2D.
- Read-only Task2A/Task2B; Smoke and Full output isolation; no git commit of pre-existing dirty work.

## Review Focus

- Duplicated/misaligned IDs must fail before PCA; Task 1 tests this.
- Empty or all-noise clustering must still produce valid tables/summary; Task 2 tests this.
- Candidate known interval overlap must exclude a novel-like designation even without Known members; Task 3 tests this.
- Background must never enter clustering fit or influence PCA component count; Task 2 tests this.
- Existing Task2A/Task2B hashes must be unchanged after both run modes; Task 5 tests this.
