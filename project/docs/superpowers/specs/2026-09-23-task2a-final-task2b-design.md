# Task2A Final and Task2B Structure Representation design

## Approved purpose and boundary

Task2A becomes a frozen high-recall proposal generator. Its known-structure recall is a scientific result and limitation, never a tuning signal or Task2B performance gate. Task2B extracts fixed embeddings and evaluates them. This run ends after Task2B reporting; no clustering, HDBSCAN, novelty decisions, or Task2C.

## Task2A Final

Consume the completed Task2A.3 small, medium, and large `window_scores.csv` files. For each scale and branch, define a paired channel p-value as the geometric mean of its two existing replicate empirical p-values, equivalent to the Task2A.3 mean replicate anomaly on the `-log10(p)` scale. This is fixed before final recall is inspected. Six channels (small/medium/large × density/shape) independently retain windows with paired `p <= 0.05`, sort by p ascending, then replicate-min anomaly descending and stable coordinates/ID. NMS is channel-local and suppresses centers at distance strictly less than half that scale's window size. All surviving proposal intervals are combined by transitive positive interval overlap. A component's representative peak is selected by minimum empirical p, then replicate-min anomaly, then coordinates/ID. Candidate inclusion and geometry never read known labels. The final candidate interval is the min/max of its member intervals. Known center/interval overlap fields are appended only afterward.

Freeze a JSON protocol before computing final recall. Record proposal threshold, channel definitions, score provenance, NMS/merge rules, tie-break, source hashes and code hash. Verify existing score hashes against the Task2A.3 manifest and old leakage/known-background audits. Engineering readiness checks protocol freeze, nonempty valid candidates, required artifacts, replicate sources, zero leakage, and no known-label tuning. It does not inspect recall magnitude. Record final center-based known recall, union coverage, descriptive annotation counts, and historical limitation honestly.

## Task2B representation

Use the Task1 validation-selected `raw` CNN checkpoint found in the manifest/comparison. Add a `forward_features()` interface returning the 64-dimensional post-linear/ReLU hidden representation immediately before dropout/final logits, while keeping `forward()` numerically unchanged. Extract canonical 6.4 kb raw matrices for each candidate/reference center and both replicates. For each of the three already-trained AE encoders, extract 3.2/6.4/12.8 kb raw matrices, apply the existing scale-specific expected vector and background-fitted O/E clip through `preprocess_shape_window`, then apply `AdaptiveAvgPool2d(1)` to the encoder feature map and flatten. Check dimensions from actual tensors. Mean rep1/rep2 features for each block, fit independent `StandardScaler`s on unlabeled Known+Background reference embeddings only, then concatenate the four transformed blocks. Transform candidate and per-replicate vectors with those same scalers. Save aligned arrays and metadata.

The 344 known structures form the known reference. Select 344 ordinary background centers deterministically from the existing strict-background large-window list, using seed 20260920 and a blocked 3.2 kb center allocation so adjacent calibration windows do not dominate. Verify no selected background large interval overlaps a known interval. For smoke, take a deterministic small subset from both references/candidates; smoke outputs are isolated and not scientific results.

Evaluate CNN-only, AE-only, and the fixed Fused embedding with a `StandardScaler`-then-`LogisticRegression` linear probe under genomic `GroupKFold` (128 kb groups), reporting fold and mean±std Accuracy, Balanced Accuracy, ROC-AUC and PR-AUC. GroupKFold separation applies to the probe. Because the frozen Task1 CNN had previously been supervised on the same known structures, CNN and Fused probe scores are descriptive and are **not** independent evidence of generalization; the AE-only result is less affected by that supervision. Do not adjust features, weights or parameters after observing scores.

Fit deterministic PCA and UMAP jointly to references and candidates using the fixed fused representation. These are visualization only. Save models, coordinates and PNGs. Quantify per-candidate replicate cosine for CNN, each AE scale and fused blocks; use explicit handling for zero vectors. A completed Task2B requires aligned fixed-dimensional embeddings, reproducible hashes, same preprocessing for candidate/reference, probe results, PCA/UMAP artifacts, consistency diagnostics and no Task2C operation. It does not require a performance threshold.

## Integrity and execution

All Task2A Final outputs live under `outputs/task2a_final`. Task2B Full outputs live under `outputs/task2b`; Smoke outputs under `outputs/pipeline_runs/task2b_smoke/outputs/task2b`. Dry run validates paths/protocol without extracting matrices. Resume validates any reusable artifact before using it. Manifests record source and output SHA256, model/scaler/probe/visualization protocols, dimensions and environment versions. Historical Task1/Task2A output files remain unchanged.
